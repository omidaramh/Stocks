نرخ‌یار - نسخه آماده استقرار

1) فایل‌ها را روی هاست PHP آپلود کنید.
2) config.php.example را به config.php تغییر نام دهید.
3) برای طلا و نقره یک API Key معتبر GoldAPI قرار دهید.
4) index.html هر ۵ ثانیه فقط api.php را صدا می‌زند و DOM نرخ‌ها را تغییر می‌دهد؛ صفحه reload نمی‌شود و موقعیت اسکرول حفظ می‌شود.
5) نرخ ارزهای AFN/EUR/GBP/USD و تومان از نرخ‌های منتشرشده توسط Da Afghanistan Bank گرفته می‌شود. این نرخ‌ها «رسمی» هستند و لزوماً نرخ بازار آزاد نیستند.
6) طلا و نقره از GoldAPI می‌آیند. برای استفاده تجاری شرایط سرویس آن را بررسی کنید.
7) برای جلوگیری از افشای کلید API، کلید فقط در config.php روی سرور قرار می‌گیرد و داخل JavaScript نیست.
8) اگر API طلا/نقره تنظیم نشده باشد، سایت قیمت ساختگی تولید نمی‌کند و وضعیت منبع را نشان می‌دهد.
